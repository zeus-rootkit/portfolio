# دليل فهم مشروع البورتفوليو — من الصفر

## 1. ابدأ من هنا
هذا المشروع موقع ثابت (Static Website): لا يحتاج قاعدة بيانات أو خادم خلفي حتى يعرض الصفحة. افتح `dist/index.html` في المتصفح. يُفضّل استخدام إضافة Live Server في VS Code لتحديث الصفحة بعد الحفظ. احتفظ بنسخة احتياطية قبل التعديل.

## 2. خريطة الملفات
- `dist/index.html`: محتوى الموقع وترتيب الأقسام والروابط؛ بداخله تعليقات عربية بعد أسطر HTML.
- `dist/styles.css`: الشكل والألوان والتجاوب والحركات؛ فُكّ ضغط قواعد CSS الطويلة إلى أسطر مع تعليق لكل خاصية.
- `dist/app.js`: القائمة، حركات الظهور، تحديد القسم الحالي، إضاءة المؤشر، والسنة؛ تعليق بجانب كل سطر ذي معنى.
- `dist/favicon.svg`: الأيقونة الصغيرة في تبويب المتصفح؛ شرح كل عنصر رسم.
- `dist/assets/hero-scene.png`: صورة القسم الرئيسي؛ ملف صورة وليس كوداً، فلا توجد أسطر برمجية للتعليق عليها.
- `.openai/hosting.json`: إعدادات الاستضافة؛ لا تغيرها إلا إذا كنت تفهم منصة النشر.

## 3. كيف تتصل الملفات؟
في HTML، السطر `<link rel="stylesheet" href="./styles.css" />` يحمل CSS، والسطر `<script src="./app.js"></script>` يحمل JavaScript. المسار `./` يعني من المجلد الحالي. الصورة تأتي من `./assets/hero-scene.png`.

## 4. فهم HTML عملياً
`<section id="about" class="about section">` يعني قسمًا له معرّف فريد `about` واسمَا تنسيق `about` و`section`. الرابط `<a href="#about">About</a>` ينقلك لهذا القسم. تغيير نص بين الوسمين يغير الكلام الظاهر. `src` للصورة، `href` للرابط، `alt` وصف للصورة، `aria-*` لدعم إمكانية الوصول. لا تحذف الوسوم الختامية دون معرفة.

## 5. فهم CSS عملياً
القاعدة `.hero h1 { color: red; }` تختار عنوان h1 داخل عنصر class اسمه hero. النقطة `.` تعني class، و`#` تعني id. المتغير `--red` معرف في `:root` وتستعمله `var(--red)`؛ غيّره لتعديل اللون الأساسي. `display:flex` يرتب العناصر بمحور، و`display:grid` ينشئ شبكة أعمدة وصفوف. `padding` مسافة داخلية و`margin` خارجية. `position:absolute` يعتمد على أقرب سلف متموضع. `z-index` ترتيب الطبقات. `@media(max-width:760px)` قواعد الهاتف. `:hover` عند مرور المؤشر، و`:before`/`:after` عناصر زخرفية. `@keyframes` يعرّف الحركة.

**مهم جداً:** توجد قواعد CSS مضافة أسفل الملف تعيد تعريف بعض الخصائص الموجودة فوق؛ عند تساوي قوة المحدد، القاعدة اللاحقة تفوز. لذلك لا تتوقع أن تغيير أول تعريف لـ `.hero-visual img` يغيّر النتيجة دائماً؛ ابحث عن جميع تعريفاته.

## 6. فهم JavaScript عملياً
`const` متغير لا يعاد إسناده. `document.querySelector` يبحث عن أول عنصر يطابق محدداً من CSS. `querySelectorAll` يعيد مجموعة عناصر. `addEventListener('click', ...)` ينفذ دالة عند النقر. `classList.toggle('open')` يضيف الصنف أو يزيله. `IntersectionObserver` يراقب ظهور العناصر عند التمرير. `?.` يمنع الخطأ إذا كانت القيمة null أو undefined. `=>` صيغة مختصرة للدوال. `forEach` يكرر العملية على عناصر المجموعة. `${...}` يدرج قيمة داخل نص بين علامتي backtick. `new Date().getFullYear()` يستخرج السنة الحالية.

## 7. عدّل الموقع بيدك: خمس تجارب آمنة
1. غيّر نص العنوان `Security beyond limits.` في HTML، ثم احفظ وحدّث المتصفح.
2. غيّر قيمة `--red` في أول CSS إلى لون آخر مثل `#00cc88`، وراقب الأجزاء التي تغير لونها.
3. بدّل ملف الصورة مع إبقاء الاسم نفسه، أو عدّل `src` إلى اسم صورة جديد داخل assets.
4. أضف رابطاً جديداً في شريط التنقل ثم أضف قسماً له `id` مطابق؛ انتبه لتنسيق الهاتف.
5. افتح أدوات المطور F12 ثم تبويب Elements/Inspector؛ اختر عنصراً وانظر أي قاعدة CSS تطبق عليه وأي قاعدة شُطبت بسبب قاعدة أحدث.

## 8. مشاكل شائعة وحلولها
- الصفحة بلا تصميم: تأكد أن `styles.css` في نفس مجلد `index.html` وأن رابط `href` صحيح.
- الصورة لا تظهر: تحقق من اسم الملف، حالة الأحرف، والمسار داخل `assets`.
- القائمة لا تفتح: تأكد أن `app.js` يحمل، وافتح Console في أدوات المطور لرؤية الأخطاء.
- التعديل لا يظهر: احفظ الملف ثم حدّث الصفحة؛ أحياناً يلزم تحديث قسري Ctrl+F5.
- عناصر مخفية: class `reveal` يبدأ بشفافية صفر، وJavaScript يضيف `visible` عند ظهور العنصر؛ تحقق من تحميل السكربت.

## 9. ترتيب التعلم المقترح
ابدأ يومين بفهم HTML وتعديل النصوص والروابط، ثم 4–7 أيام لفهم CSS وتجربة Flexbox وGrid والتجاوب، ثم 3–5 أيام لأساسيات JavaScript وتطبيقها على قائمة الهاتف والحركات. هذه أوقات تدريب تقريبية وليست وعداً بإتقان اللغات.

## 10. تنبيه دقة المحتوى
بيانات الشهادات ونسب التقدم ومواعيد الامتحانات في HTML هي نصوص ثابتة وليست متصلة بحساباتك؛ راجعها وعدّلها يدوياً قبل نشر الموقع. كذلك بعض بطاقات المشاريع وصفية وليست روابط لمشاريع منشورة.
